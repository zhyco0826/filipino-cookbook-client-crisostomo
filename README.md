# Filipino Cookbook Client Application

A web client application that consumes and displays data from the Filipino Cookbook REST API.

## Features
- Renders recipes, categories, and ingredient listings in a clean user interface.
- Processes raw JSON responses into styled UI elements.

## Technologies Used
- PHP, HTML5, CSS3, JavaScript
- XAMPP / Apache

## API Source and Acknowledgment
This client application consumes the Filipino Cookbook API developed by:
- **Developer:** jnrick
- **Repository:** https://github.com/jnrick/filipino-cookbook-api

## API Endpoints Used
- `GET /api/foods`
- `GET /api/categories`

## Installation
1. Clone this repository: `git clone https://github.com/zhyco0826/filipino-cookbook-client-crisostomo.git`
2. Run via Apache on XAMPP.
